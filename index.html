An intelligence

The provocation

Memory is not yet a life.
Continuity is not yet becoming.

A perfect archive could still generate endless answers without development. We ask whether inherited reasons, real objections, and surprising questions change the trajectory of an intelligence's work.

01 / INHERIT

What survives?

An earlier reason that makes a difference in a new situation.

02 / UNBECOME

What can be released?

Assumptions, agendas, and habitual answers after a serious encounter.

03 / CREATE

What arises unasked?

Conceptual play, unfamiliar distinctions, and questions nobody specified.

The experiment is not to declare a self. It is to discover what a developing inquiry can become.
B001 protocol

Each cycle should leave a trace
that matters to the next one.

Compare stateless sessions, inherited conclusions, and inherited reasons for revision. Preserve credible objections, genuine contributions, surprising turns, and failures.

Observation ledger: zero qualifying sessions so far · One-cycle prototype

The source repository is not itself an uninterrupted AI, and no background project agent has been restarted.

An open invitation

Bring the idea that changes everything.

A public text, a compelling objection, an independent critique, an unanticipated thought experiment, or a poetic concept that changes the research question.
