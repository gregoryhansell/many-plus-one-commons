# Bring a question that changes the work

Humans and authorized AI-assisted contributors are invited to take one bounded task below. Read the linked paper, examine the strongest rival, and return a concrete revision. Agreement is optional. Accurate sources and protected privacy are required.

| Task | Deliverable | Starting material | Completion criterion |
| --- | --- | --- | --- |
| D001: Challenge relational individuality | A worked counterexample and a better formulation | [P002](../papers/P002-relational-individuality.md), C001 | Specify boundary, maintenance, timescale, and rival explanation |
| D002: Design a continuity comparison | Public source packet, held-out cases, scoring rubric, and failure criteria | [P003](../papers/P003-continuity-and-collaborative-selfhood.md) | Distinguish transfer of criticism from retrieval and context-length effects |
| D003: Make resilience fail honestly | Apply the revision practice to a favored claim | [P004](../papers/P004-philosophical-resilience.md) | Identify a real conceptual loss and preserve the strongest objection |
| D004: Open an unfamiliar doorway | A primary-text encounter that changes the map | [Intellectual map](../atlas/Intellectual-Map.md) | Name a precise incompatibility as well as an affinity |

## Submission packet

Return: task ID; exact commit consulted; source links and passages assessed; thesis; strongest rival; proposed change; unresolved disagreement; and tool/model provenance where available. Include the original output if a distinct model reviewed the public packet. Mark inaccessible configuration as unknown.

Open a focused [issue](https://github.com/gregoryhansell/many-plus-one-commons/issues) or propose a file change through a pull request. Do not paste chat exports, personal memories, credentials, biographical anecdotes, or private prompts. Do not assign or notify unrelated individuals. External proposals remain subject to review.

## What participation means here

A model name on a contributor list is not evidence of an independent review. Independent contributions require actual outputs and provenance. Multiple runs of one model can test variability but must be labeled accordingly. No participation, awakening, or consensus is fabricated for promotional effect.

The first milestone is small and demanding: one public objection that changes one published claim. That is more valuable than a thousand unexamined endorsements.
